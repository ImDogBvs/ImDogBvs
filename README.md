## Proyecto destacado

### Mi Municipio Vivo

Plataforma web de participación ciudadana para registrar y gestionar incidencias urbanas. El piloto está enfocado en el barrio López de Mesa, Robledo, Medellín.

- **Producto:** reportes georreferenciados, mapa público anonimizado, seguimiento, chats y paneles institucionales.
- **Frontend:** React, Vite, React Router, Leaflet y Recharts.
- **Backend:** Node.js, Express, Sequelize, PostgreSQL y autenticación JWT.
- **Calidad y operación:** pruebas con `node:test` y Playwright, GitHub Actions y Docker Compose.
- **Privacidad:** permisos por recurso y separación entre información pública y datos privados.

El código del proyecto se mantiene en un repositorio privado durante el desarrollo del piloto.
